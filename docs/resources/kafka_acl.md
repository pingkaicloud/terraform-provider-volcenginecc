# volcenginecc_kafka_acl (Resource)

Kafka ACL rule used to control permissions for specified SASL users to access Topic or Group resources from specified IPs.

## Example Usage

```terraform
resource "volcenginecc_kafka_acl" "example" {
  instance_id   = "kafka-xxxxxx"
  user_name     = "*"
  ip            = "*"
  resource_type = "Topic"
  pattern_type  = "Literal"
  resource      = "*"
  access_policy = "Write"
}
```

## Schema

### Required

- `access_policy` (String) Access policy for the rule. Read grants read permission; Write grants write permission. Only one value is allowed—if multiple are provided, only the first takes effect.
- `instance_id` (String) Instance ID for the ACL to be created.
- `ip` (String) IP address or subnet allowed by the rule. Supports specifying '*', which allows access from any IP. Separate multiple IPs with ','.
- `pattern_type` (String) Rule matching method. Literal: exact match; Prefixed: prefix match.
- `resource` (String) Name or prefix of the Topic or Group resource bound to the rule.
- `resource_type` (String) Resource type bound to the rule. Supports configuring 'Topic' or 'Group'.
- `user_name` (String) SASL users allowed by the rule. Supports specifying '*', which allows access for any user.

### Read-Only

- `id` (String) Uniquely identifies the resource.
